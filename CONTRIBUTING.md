# Contributing

Thank you for helping improve Essential SEO Toolkit.

1. Search existing issues before opening a focused bug or feature request.
2. Never attach private pages, customer URLs, credentials or browsing data.
3. Create a branch from `main` and keep each pull request to one change.
4. Run `npm test` and include the result and manual Chrome version tested.
5. Explain user-visible changes and update documentation where necessary.

By contributing, you agree that your work may be distributed under the MIT Licence.
